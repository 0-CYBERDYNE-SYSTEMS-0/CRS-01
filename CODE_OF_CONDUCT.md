# Code of Conduct

## Our standard

The goal of CRS-01 is an honest, evidence-first knowledge graph. To keep the community
productive, everyone participating in this project — issues, pull requests, discussions —
is expected to behave professionally:

- Use welcoming and inclusive language; assume good faith.
- Critique code and claims, not people. Disagreements about evidence are the project's
  lifeblood; disagreements about people are not welcome.
- No harassment, trolling, insults, personal attacks, or publishing others' private
  information.
- Stay on topic: cannabis breeding genetics, data quality, and the craft of building this
  tool.

## Scope

This conduct applies within project spaces (repository, issues, PRs, discussions) and when
representing the project publicly.

## Enforcement

Report unacceptable behavior to the maintainers privately (use GitHub's "Report" tooling on
the offending content, or contact the repository owner through GitHub). Reports will be
reviewed and responded to as feasible; repeated or serious violations result in a ban from
project spaces.

Maintainers are held to the same standard and may face stricter consequences for violating
it.
